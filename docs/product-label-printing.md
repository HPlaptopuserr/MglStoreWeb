# Үнийн шошго хэвлэх

Vendor → Бараа → Шошго хэвлэх болон POS-ийн хамтын `ProductLabelPrintDialog` ашиглана.

- «Загвар» нь сонгосон цаасны бүх талбай, миллиметрийн хэмжээ, чиглэл, хэвлэх зах болон тухайн хуудасны шошгуудыг харуулна. A4/A5/Letter-ийн олон хуудсыг өмнөх/дараах товчоор үзнэ. Кассын горимд бүх сонгосон шошго нэг рулон дээр доошоо дараалан харагдах бөгөөд хэсгийг доош гүйлгэж үзнэ.
- A4, A5, Letter: шошгоны өргөн/өндөр, зах, мөр хоорондын зайгаар багтаамж тооцно.
- «Кассын принтер»: 58 мм, 80 мм, эсвэл 40–120 мм-ийн өөр өргөн оруулна. Нэг шошгоны цаасны урт 24–300 мм; зах 0–20 мм. Шошго нь захыг хассан талбайг ашиглана; бүх шошго нэг үргэлжилсэн рулон болно. Нийт урт = шошгоны тоо × нэг шошгоны урт + (тоо − 1) × хоорондын зай. Хэвлэх HTML нь шошго бүрээр хуудас таслахгүй, нийт рулоны уртыг @page хэмжээнд өгнө.
- Кассын загвар хар цагаан: жижиг лого, хоёр мөр хүртэлх зүүн зэрэгцүүлсэн нэр, тусдаа мөрөнд том үнэ, доод хэсэгт баркод ба кодын дугаар. Үнийн мянгатын тусгаарлагч, жижиг ₮ тэмдэглэгээтэй. Шошгоны өндрөөр зайг хуваарилна.
- Урьдчилсан харагдац болон хэвлэх HTML нь нэг renderer ашигладаг. Хэрэглэгчийн текст HTML-escape хийгдэнэ; preview iframe script ажиллуулахгүй.
- Хэвлэх цонхноос бодит принтерээ сонгож, драйверийн цаасны хэмжээг тохируулна. Масштаб 100%, толгой/хөлгүй хэвлэнэ. Принтерийн драйвер зөвшөөрөөгүй хэмжээ, cutter, raw ESC/POS удирдлагыг браузер автоматаар тохируулахгүй.

«Хэвлэх үнэ» сонголтоор энгийн (`price`) эсвэл бөөний (`wholesalePrice`) үнийг бүх сонгосон шошгонд хэрэглэнэ. Хоёр төрлийн үнийг тусад нь засварлах ба сонголт солиход засвар алдагдахгүй. Бөөний үнэ бүртгэлгүй бол хоосон гэж мэдээлж, энгийн үнээр орлуулахгүй; дүнг оруулах хүртэл хэвлэх товч идэвхгүй. Хэвлэмэл шошго дээр үнийн төрөл харагдана.

## Баталгаажуулалт

`pnpm --filter @mgl/api exec tsx --test ../../packages/ui/test/product-label-print.test.ts`

9 тест: A4-ийн чиглэл ба багтаамж, 58/80/тусгай хэмжээ, цувааны дараалал ба хуулбарын тоо, зах ба нийт урт, багтахгүй хэмжээ, үнэний төрөл ба бүртгэлгүй үнэ, олон хуудас, HTML аюулгүй дүрслэл. UI, Vendor, POS TypeScript шалгалт тэнцсэн. A4 болон 80×50 мм-ийг localhost:3002/products дээр браузерт харагдацаар шалгасан. Бодит принтерээр хэвлэж, баркод сканнердаж туршаагүй. Үндсэн серверт нийтлээгүй.

## POS-H58 болон өөр драйвертэй принтер

- POS-H58 USB принтер дээр «Цаас / принтер → Кассын принтер», «Рулоны хэмжээ → 58 мм» сонгоно. Кассын шинэ сонголтын үндсэн өргөн 58 мм; A4 хэвлэх сонголт хэвээр байна.
- Сонгосон шошгоны тохиргоо энэ браузерт хадгалагдаж, дараагийн нээлтэд сэргээгдэнэ.
- Хоосон цаас эсвэл хэт урт зай гарвал «Цаасны хэмжээний горим → Принтерийн цаасны тохиргоогоор» сонгоно. Энэ горим драйверийн цаасны хэмжээг ашиглана. Драйвер дээр мөн 58 мм рулон, тохирох уртыг сонгох шаардлагатай. «Шошгоны нийт уртаар» горим нь өмнөх тусгай урттай хуудсыг ашиглана.
- Хэвлэх цонхонд хэмжээ 100%, зах None, Headers and footers унтраалттай байна. A4 шошгоны загварыг 58 мм рулон дээр бүү хэвлэ.
- Борлуулалтын баримтын харагдац болон хэвлэх мэдэгдэлд ижил төрлийн хоёр горим нэмсэн; тэдгээрийн тохиргоо шошгоноос тусдаа хадгалагдана. Автомат хэвлэлт, дахин хэвлэлт хадгалсан баримтын тохиргоог ашиглана.
- Эдгээр нь браузерийн хэвлэх өөрчлөлт. ESC/POS raw USB холболт, драйверийн feed/cutter тохиргоог удирдахгүй. Бодит POS-H58 дээр туршиж баталгаажуулна.

### Борлуулалтын баримтын тусдаа хэвлэх цонх

Баримтын харагдац болон борлуулалтын дараах мэдэгдлийн «Тусдаа цонхоор хэвлэх» товч нь баримтыг харагдах шинэ цонхонд нээнэ. Хэвлэх цонх load, fonts, хоёр paint frame-ийн дараа нээгдэх бөгөөд баримтын цонх хэвлэсний дараа автоматаар хаагдахгүй. «Дахин хэвлэх» эсвэл браузерийн system dialog ашиглан дахин оролдож болно. Popup хаагдсан бол сайт дээр алдаа харуулна. Төлбөр дууссаны дараах автомат хэвлэлт iframe ашигласан хэвээр. Энэ хувилбар нь принтер дээрх хоосон хэвлэлтийн шалтгааныг баталсан гэсэн үг биш; бодит принтер дээр харьцуулж туршина.
