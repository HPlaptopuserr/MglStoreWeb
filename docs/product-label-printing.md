# Үнийн шошго хэвлэх

Vendor → Бараа → Шошго хэвлэх болон POS-ийн хамтын `ProductLabelPrintDialog` ашиглана.

- «Загвар» нь сонгосон цаасны бүх талбай, миллиметрийн хэмжээ, чиглэл, хэвлэх зах болон тухайн хуудасны шошгуудыг харуулна. A4/A5/Letter-ийн олон хуудсыг өмнөх/дараах товчоор үзнэ. Кассын горимд бүх сонгосон шошго нэг рулон дээр доошоо дараалан харагдах бөгөөд хэсгийг доош гүйлгэж үзнэ.
- A4, A5, Letter: шошгоны өргөн/өндөр, зах, мөр хоорондын зайгаар багтаамж тооцно.
- «Кассын принтер»: 58 мм, 80 мм, эсвэл 40–120 мм-ийн өөр өргөн оруулна. Нэг шошгоны цаасны урт 24–300 мм; зах 0–20 мм. Шошго нь захыг хассан талбайг ашиглана; бүх шошго нэг үргэлжилсэн рулон болно. Нийт урт = шошгоны тоо × нэг шошгоны урт + (тоо − 1) × хоорондын зай. Хэвлэх HTML нь шошго бүрээр хуудас таслахгүй, нийт рулоны уртыг @page хэмжээнд өгнө.
- Кассын загвар хар цагаан: жижиг лого, хоёр мөр хүртэлх зүүн зэрэгцүүлсэн нэр, тусдаа мөрөнд том үнэ, доод хэсэгт баркод ба кодын дугаар. Үнийн мянгатын тусгаарлагч, жижиг ₮ тэмдэглэгээтэй. Шошгоны өндрөөр зайг хуваарилна.
- Урьдчилсан харагдац болон хэвлэх HTML нь нэг renderer ашигладаг. Хэрэглэгчийн текст HTML-escape хийгдэнэ; preview iframe script ажиллуулахгүй.
- Хэвлэх цонхноос бодит принтерээ сонгож, драйверийн цаасны хэмжээг тохируулна. Масштаб 100%, толгой/хөлгүй хэвлэнэ. Принтерийн драйвер зөвшөөрөөгүй хэмжээ, cutter, raw ESC/POS удирдлагыг браузер автоматаар тохируулахгүй.

«Хэвлэх үнэ» сонголтоор энгийн (`price`) эсвэл бөөний (`wholesalePrice`) үнийг бүх сонгосон шошгонд хэрэглэнэ. Хоёр төрлийн үнийг тусад нь засварлах ба сонголт солиход засвар алдагдахгүй. Бөөний үнэ бүртгэлгүй бол хоосон гэж мэдээлж, энгийн үнээр орлуулахгүй; дүнг оруулах хүртэл хэвлэх товч идэвхгүй. Хэвлэмэл шошго дээр үнийн төрөл харагдана.
