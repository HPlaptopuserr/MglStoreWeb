# Онлайн захиалгын төлбөр хайх

Админ → **Төлбөр хайх** (`/payments`). API: `GET /api/admin/payments/search`.
Зөвхөн `ADMIN`, `SUPER_ADMIN` эрхтэй. Хайлтын үр дүн хадгалагдахгүй (`Cache-Control: no-store`).

## Хайлтын төрлүүд

- **Захиалга / төлбөрийн лавлахаар хайх**: `Order.orderNumber`, `PaymentAttempt.providerRef` доторх хэсгээр, том жижиг үсэг ялгахгүй хайна. 3–1000 тэмдэгт шаардлагатай.
- **Хаалтын дүн тулгах**: `QR ХААЛТ` утгын `YYYY.MM.DD` (эсвэл `/`, `-`) огноог авч эсвэл гараар сонгосон огноогоор, Улаанбаатарын 00:00–24:00 хооронд төлөгдсөн онлайн QPay захиалга бүрийн дүнг тулгана. Minu-ийн шимтгэл анхдагчаар 1%, нэмэлт суутгал 0₮. Нэмэлт суутгалыг зөвхөн мэдэгдэж байгаа үед оруулна.

Тооцоолол: `цэвэр дүн = төлсөн дүн × (1 − шимтгэл / 100) − нэмэлт суутгал`, мөнгөний хоёр оронгоор тоймлоно. Prisma Decimal ашиглана. Хуудас бүрт 20 төлбөр.

Банкны хаалтын код нь хадгалагдсан нэхэмжлэхийн лавлахтай адил биш. Энэ хайлт POS, олон захиалгын нийлбэр хаалт, бусад үйлчилгээний төлбөрийг хамрахгүй. Огноо ба дүн таарсан үр дүн нь боломжит тохирол бөгөөд эзнийг баталсан нотолгоо биш; Minu-ийн хаалтын тайлангаар баталгаажуулна. Төлбөрийн болон захиалгын төлөв өөрчлөхгүй.

## Шалгалт

- `pnpm --filter @mgl/types build`
- `pnpm --filter @mgl/api type-check`
- `pnpm --filter @mgl/admin type-check`

- Шинэ UI файлуудыг суулгагдсан Next.js ESLint-ийн core-web-vitals болон TypeScript дүрмээр шалгасан. Админ апп үндсэн ESLint config-гүй тул `work/payment-search/eslint.config.mjs` түр config ашигласан.

Локал сангийн бодит лавлах болон хаалтын API хайлтыг зөвхөн унших горимоор тулгаж шалгасан. Үндсэн серверт нийтлээгүй.
